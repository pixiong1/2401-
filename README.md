# 2401班量化管理系统

一个面向班级的**导师制量化管理 + 积分激励平台**：导师给 36 名学生加减分（正负分 + 事由），自动生成排行榜；支持**批量录入**（选择式 / 表格式模板）、**成绩录入与排名量化**（进步加分、退步扣分）、**钉钉消息提醒**；班主任批量导入学生、分配班委与导师小组、审核班委提交的评分。支持多角色、全员公示、账号统一由班主任生成。

- **零依赖**：后端只用 Node.js 原生模块，不需要 `npm install`
- **数据自持**：所有数据存 `data/db.json`（JSON 文件数据库），支持一键导出/导入备份
- **即拿即用**：首次启动自动生成 1 超级管理员 + 若干导师/学生演示账号；清空重来只需删除 `data/db.json` 重启
- **适合局域网 / 自建服务器部署**：小巧稳定，玩客云、树莓派、家用 NAS 都能跑

## 二、角色与权限模型

| 角色 | 能力 |
|---|---|
| **超级管理员 `admin`** | 上帝视角：可查看/管理一切、审核班委评分；**不算老师**，在老师列表与老师统计中隐藏，但可正常登录访问 |
| **班主任**（如 `YINGYUquhaizeng` 曲海增） | 审核班委提交的评分、学生管理、账号管理、**成绩录入与确认**、备份、系统设置 |
| **导师** | 可记录**全部**学生的量化（不限于本组），评分直接生效；可查看成绩 |
| **班委** | 可给同学评分，提交后需班主任/超管审核 |
| **学生** | 可查看全部评分流水、排行榜、**自己的成绩**；可提交评分（需审核） |

## 三、账号体系

**注册入口已关闭**，所有账号统一由班主任（或超级管理员）生成。

### 首次启动自动生成的预置账号（演示用）

| 角色 | 账号 | 初始密码 |
|---|---|---|
| 超级管理员 | `admin` | `admin123` |
| 导师 | `t01` ~ `t05` | `123456` |
| 学生 | `240101` ~ `240136`（学号即账号） | `123456` |

> 以上为预置**演示账号**。真实使用时不要使用预置数据。

### 真实使用流程

- **学生**：班主任在「学生管理」下载名单模板（.csv）→ 填写真实名单 → 上传，导入后**自动按学号生成账号，默认密码统一为 `123456`**
- **导师**：班主任在「账号管理」中创建导师账号
- **班主任 / 超级管理员**：由部署者直接建立
- **所有账号**登录后都可在「修改密码」中自行改密（首次登录强烈建议立即修改）

> 班委由班主任在学生管理中分配。班委提交的评分需班主任 / 超级管理员审核后才生效。

> **自动登录**：登录一次后，浏览器会记住登录状态（cookie，有效期 90 天）。之后打开网站会直接自动进入系统，无需再输入账号密码；点「退出」才会清除。

## 四、本地运行

需要电脑已安装 [Node.js](https://nodejs.org/)（16 及以上，推荐 18+）。

```bash
cd 2401-quant-platform
node server.js
```

浏览器打开 **http://localhost:3000** 即可使用。
同一局域网内，其他设备可访问启动时打印的 `局域网访问` 地址（例如 http://192.168.31.180:3000）。

> 修改端口：Windows 执行 `set PORT=8080` 后运行 `node server.js`；Linux/Mac 用 `PORT=8080 node server.js`。

## 五、部署到服务器 / 玩客云（推荐）

后端是标准 Node.js HTTP 服务，任何支持 Node 的环境都能跑。以 Linux / 玩客云（刷 Armbian 等）为例：

```bash
# 上传工程到服务器
scp -r 2401-quant-platform root@你的服务器IP:/opt/
ssh root@你的服务器IP
cd /opt/2401-quant-platform

# 安装 node（若已安装可跳过）
# 启动
node server.js
```

**建议用 systemd 常驻运行**（开机自启、崩溃自动重启），以 `qms` 服务为例：

```bash
cat > /etc/systemd/system/qms.service <<'EOF'
[Unit]
Description=2401 Quant Platform
After=network.target
[Service]
WorkingDirectory=/opt/2401
ExecStart=/usr/local/bin/node server.js
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload
systemctl enable --now qms
```

> 学校/异地访问：需要给服务器配置公网可达地址（公网 IP、内网穿透如花生壳、或云主机），并注意 **HTTPS 页面访问 HTTP 服务会被浏览器拦截**（Mixed Content），穿透时尽量使用 HTTPS。

## 九、成绩录入与量化规则（班主任操作流程）

1. 班主任进入「成绩管理」→ 填写考试名称（如：10月月考）→ 下载成绩模板（.csv）
2. 用 Excel / WPS 打开模板填写：**固定列**（姓名、学号、总成绩、原始分选填、班级排名选填、年级排名选填）+ 其他列自动识别为科目成绩
3. 上传成绩表 → 系统自动按总分排班级名次（也可手工填班级排名）
4. 班主任点击「确认并生成量化分」：与上次年级排名对比，**进步 x 名加 x 分，退步 x 名减 x 分**，事由自动写「成绩排名进/退步×名」
5. 学生登录「我的成绩」即可查看自己历次成绩、排名与进退步（学生之间互不可见）
6. 已确认的批次不可删除；未确认批次可删除重传

## 十、钉钉提醒配置（班主任操作流程）

1. 在钉钉群 → 群设置 → 群机器人 → 添加「自定义机器人」，复制 Webhook 地址（含 access_token）
2. 班主任登录平台 → 「系统设置」→ 粘贴 Webhook → 保存
3. 之后任何学生积分变动（导师/班主任录入、审核通过、成绩量化确认）都会自动向对应导师发送钉钉消息
4. 留空即不发送；机器人安全设置若设了关键词，需在消息中含有关键词才能发送
